📖 자서전 인터뷰 질문지 (샘플)

삼대동행 프로젝트 · 아래 질문을 참고하여 인터뷰를 진행해 주세요

🧬 인생 이야기 중심 — 기본질문 10개

  1. 언제 어디에서 태어나셨나요?
  2. 어린 시절 기억 중 가장 기억에 남는 순간이나 추억이 있으시면 말씀해주세요.
  3. 살던 집, 동네, 고향은 어떤 곳이셨나요? 기억나는 것이 있으시면 자세히 해주세요.
  4. 아버지나 어머니에 대한 가장 기억에 남는 이야기나 추억이 있다면 말씀해주세요.
  5. 학교 다닐 때 가장 기억에 남는 선생님이나 친구는 누구였고, 어떤 추억이 있으셨나요?
  6. 결혼은 언제, 어떻게 하셨는지? 결혼할 때의 기억나는 일화가 있다면 말씀해주세요.
  7. 자녀가 태어났을 때의 기억이나, 어린 시절의 추억 중 특히 기억나는 순간이 있다면 말씀해주세요.
  8. 지금 살고 계신 집과 동네는 어떤가요?
  9. 요즘 즐거운 일이나 활력을 주는 일이 있으시면 말씀해주세요.
  10. 자녀나 손주들에게 남기고 싶은 이야기나 조언이 있으시다면 말씀해주세요.

상황에 맞는 녹음 방법을 확인해 주세요

📞 전화 통화 인터뷰 녹음 방법

  1. 통화 인터뷰는 사용하시는 휴대폰의 기본 전화 앱의 '통화 녹음' 기능을 사용해 주시면 됩니다.
  2. 통화 시작 후 통화 화면의 '녹음' 버튼을 눌러 녹음을 시작하고, 인터뷰가 끝나면 다시 눌러 중지·저장해 주세요.
  3. 녹음 전에는 반드시 상대방에게 통화 내용 녹음에 동의를 구해 주세요.
  4. 기종별 상세 방법이 필요하시면, "(갤럭시/아이폰) + 통화 녹음 설정"으로 검색해 안내를 참고해 주세요.

🎤 스마트폰으로 인터뷰 녹음하는 방법

  1. 조용한 장소에서 인터뷰를 진행해 주세요.
  2. 스마트폰의 기본 음성 녹음 앱(또는 평소 사용하시는 녹음 앱)을 실행해 주세요.
  3. 마이크가 가려지지 않도록 휴대폰을 말하는 사람 쪽으로 30cm 내외 거리에서 두세요.
  4. 인터뷰 시작 전에 테스트 녹음 5초 정도를 해 보고, 재생해서 소리가 잘 들리는지 확인해 주세요.
  5. 인터뷰를 시작할 때 녹음 버튼을 눌러 시작, 인터뷰가 모두 끝난 뒤 정지 버튼을 눌러 저장해 주세요.
  6. 파일 이름에 인터뷰이 이름과 날짜를 적어 저장해 주세요 (예: "홍길동_인터뷰_2026-05-10").
  7. 저장된 음성 파일을 samdaedonghang@gmail.com으로 보내 주세요.
